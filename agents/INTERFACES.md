# Module interfaces (contract between workstreams)

Agents work in parallel against these signatures. Stub a dependency that isn't merged yet; never change a
signature without the coordinator. **Run this file through the plan review loop before Wednesday.**

All code lives in `bot/` (it is the submission: stdlib + numpy + scipy only). Cards are ints
`id = rank * 4 + suit`, with rank 0..12 = `2..A` and suit 0..3 = `s h d c`.

| Module | Owner | Public API |
|---|---|---|
| `bot.py` | W1 | Protocol loop only (`main()`): reads lines, dispatches to `Brain`, writes replies. The only stdout writer (it saves the pipe and redirects `sys.stdout` to stderr). Never raises; exactly one reply per request. |
| `brain.py` | W1 | `class Brain`: `on_init(msg)`, `on_new_hand(msg)`, `act(req) -> dict`, `discard(req) -> dict`, `on_discard_result(msg)`, `on_hand_result(msg)`, `on_notice(msg)`, `on_match_end(msg)`. Wires the modules below; owns the fallbacks. |
| `legal.py` | W1 | `make_legal(action: dict, req: dict) -> dict`: always returns a complete legal reply (01/R2). `make_legal_discard(card, req) -> dict`, `legal_list(req) -> list[str] \| None`, `fallback_action(req) -> dict`, `fallback_discard(hole) -> str`, `to_int(x, default) -> int`. All total (never raise). |
| `timing.py` | W1 | `class Clock(leg: LegState)`: `start(req)`, `budget_ms(kind: str) -> float` (kind ∈ preflop/flop/discard/turn/river), `elapsed_ms() -> float`, `expired(budget_ms: float) -> bool`, `tier() -> "normal"/"throttle"/"panic"` (02/E5). |
| `state.py` | W1 | `class HandState`: seat, `hole3` (our 3 pre-discard ints), `hole` (current ints), `hole_strs`, board, street, pot, bets, stacks, history, `my_discard`, `opp_discard`, `dead` (bytearray(52), rebuilt after every update); `update_from_request(req)`, `update_from_discard_request(req)`, `update_from_discard_result(msg)`. `class LegState`: init config, hands played, net, notices, results. |
| `cards.py` | W1 → W2 | `parse(s) -> int`, `fmt(c) -> str`, `is_valid(s) -> bool`, `parse_valid(list) -> list[int]`, `RANKS`, `SUITS`, `RANK`, `SUIT`; `pair_index(a, b) -> int` (0..1325, `hi*(hi-1)//2 + lo`), `PAIRS[i] -> (lo, hi)`, `dead_mask(cards) -> bytearray(52)`, `deck_without(dead) -> list[int]`. **Built.** |
| `evaluator.py` | W2 | `eval7(cards: Sequence[int]) -> int` (5–7 distinct ids, higher is better, equal hands give equal ints; value = `cat<<20 \| kickers`, cat 0 = high card … 8 = straight flush; input not validated); `category(value) -> int`; `warm()` (optional, fills the memo tables in ~0.3 s; call at start-up). `eval_batch` is deferred (02/E2). **Built.** |
| `equity.py` | W2 | `equity(hero2, board, opp_weights=None, dead=None, budget_ms=0.0, rng=None) -> (eq, n_eff)`: hero2 = 2 cards; board = 3–5 cards; opp_weights = None (uniform), a length-1326 sequence indexed by `pair_index`, or a dict `{(a, b): w}`; `dead` = `HandState.dead` (must hold our 3 dealt cards, the board and their discard); budget ≤ 0 → exactly 64 samples; flop/turn sample pairs in proportion to weight, river enumerates exactly when it fits the budget. Common-random-number helpers: `deal_samples(board, opp_weights, dead, n, rng)`, `deal_triple_samples(board, dead, n, rng, keep_fn)` (opponent dealt 3 cards, `keep_fn(triple, board)` picks their pair), `equity_vs_samples(hero2, board, samples) -> float`; a sample is `((a, b), runout)`. `canon3(cards3) -> int` (0..1754). **Built.** |
| `discard.py` | W3 | `flop_score(pair, flop) -> float` (the static score S of 03/D3) and `draw_potential(pair, flop) -> float`; `opp_discard_policy(triple3, flop) -> int` (keeps the max-S pair; uses only the opponent's own cards + the flop); `choose_discard(hole3, flop, opp_model, dead, budget_ms, rng, *, betting_possible=True, max_samples=None) -> int` (card id to discard; budget ≤ 0 or any failure → the max-S keep; `opp_model` may provide `triple_weight(triple, flop)` and `discard_policy(triple, flop)`); `posterior_after_discard(d_v, flop, prior=None, beta=None, *, dead=None, flop_action=None, toss_lowest=False, eta=None) -> np.ndarray(1326)` indexed by `pair_index`, usable directly as `opp_weights` (prior = None, a length-1755 class-mass array, or a callable per triple); `MULT` = physical triples per `canon3` class. **Built.** |
| `preflop.py` | W4 | `strength(hole3) -> float` (table lookup, equity vs random; heuristic if the table is missing); `percentile(hole3) -> float` (share of the 22,100 physical hands ranked below); `equity_vs_top(hole3, width) -> float` (equity vs the opponent's top-`width` range); `heuristic(hole3) -> float`; `decide(req, hand_state=None, opp=None, rng=None) -> dict` (action intent; never raises). Reads `opp.stat` for `hands`, `vpip`, `pfr`, `three_bet`, `shove`, `fold_to_steal`, `fold_to_bet`, and uses them only once `hands >= 20`. Data: `bot/data/preflop.json` (generated by `scripts/offline/build_preflop_table.py`). **Built.** |
| `betting.py` | W5 | `decide(req, hand_state, opp, clock, rng) -> dict \| None` for the flop (3 hole cards, best-keep equity) and turn/river (2 cards, equity vs the range after their discard); `None` only when our hole cards are unknown (the brain then falls back). Helpers: `bet_amount(spot, f, spr_shove=None) -> int` (raise-to arithmetic, clamp, shove-snap), `calls(eq, to_call, pot, street, ip, no_future) -> bool`, `bluff_prob`, `semi_prob`, `preflop_play(history, reads, info)`, `opp_range(req, hand_state, opp) -> ndarray(1326)`, `stats`. Reads `opp.stat` and `opp.archetype_weights()`. **Built.** |
| `opponent.py` | W6 | `class OppModel`: updated once per hand from `hand_result` (via `Brain.on_hand_result`); `stat(name) -> float` for `hands`, `vpip`, `pfr`, `three_bet`, `shove`, `fold_to_steal`, `fold_to_bet` (+ `_flop/_turn/_river`), `agg_freq`, `aggression`, `allin`, `size_corr`, `discard_tau`, `toss_rate`, `toss_lowest`, `showdowns`, `mdf_tilt` (unknown names → 0.0; all counts decay with a 70-hand half-life); `archetype_weights() -> dict` over `station`, `nit`, `random`, `maniac`, `neutral` (sums to 1, starts all-neutral); `range_weights(...)` returns None (ranges live in `betting.py`). **Built.** |
| `replay.py` | W6 | Rebuilds bets, stacks, pot and all-ins from an engine `history`, following the engine's rules; used by `opponent.py` and `betting.py`. **Built.** |
| `log.py` | W1 | `log(*parts)` (debug, only with `POKERBOT_DEBUG=1`), `warn(*parts)` (always), `log_exc(where)`. stderr only, capped at 48 KB, never raises. |
| `placeholder.py` | W1 | `v0_action(req)`, `v0_discard(hole_cards)`: champion v0 behaviour. Deleted once F04–F06 replace it. |
| `params.py` | all | Tunables only, one section per workstream (`# --- W5 ---`). No logic. |

Rules:
- **Pure functions where possible**, so they can be tested without the engine.
- Every function that can take time gets a `budget_ms` or `clock`, and stops on time.
- No module except `bot.py` writes to stdout. Debug logging goes through a `log()` helper to stderr, off by default.
