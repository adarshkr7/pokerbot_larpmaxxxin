# Module interfaces (contract between workstreams)

Agents work in parallel against these signatures. Stub a dependency that isn't merged yet; never change a
signature without the coordinator. **Run this file through the plan review loop before Wednesday.**

All code lives in `bot/` (it is the submission: stdlib + numpy + scipy only). Cards are ints
`id = rank * 4 + suit`, with rank 0..12 = `2..A` and suit 0..3 = `s h d c`.

| Module | Owner | Public API |
|---|---|---|
| `bot.py` | W1 | Protocol loop only: reads lines, dispatches to `Brain`, writes replies (`# protocol`). Never raises. |
| `brain.py` | W1 | `class Brain`: `on_init(msg)`, `on_new_hand(msg)`, `act(req) -> dict`, `discard(req) -> dict`, `on_discard_result(msg)`, `on_hand_result(msg)`, `on_notice(msg)`. Wires the modules below; owns the fallbacks. |
| `legal.py` | W1 | `make_legal(action: dict, req: dict) -> dict`: always returns a legal action (01/R2). `fallback_action(req) -> dict`, `fallback_discard(hole) -> str`. |
| `timing.py` | W1 | `class Clock`: `start(req)`, `budget_ms(kind: str) -> float` (kind ∈ preflop/flop/discard/turn/river), `expired() -> bool`, `tier() -> "normal"/"throttle"/"panic"` (02/E5). |
| `state.py` | W1 | `class HandState`: seat, hole (ints), board, history, pot, our discard, opponent discard, `dead` (bool[52]). `class LegState`: hands played, results. |
| `cards.py` | W2 | `parse(s) -> int`, `fmt(c) -> str`, `RANK`, `SUIT`, `deck_without(dead) -> list[int]`. |
| `evaluator.py` | W2 | `eval7(cards: Sequence[int]) -> int` (5–7 cards, higher is better); `eval_batch(arr: np.ndarray[N, 7]) -> np.ndarray[N]`. |
| `equity.py` | W2 | `equity(hero2, board, opp_weights, dead, budget_ms, rng) -> (eq, n_eff)`: hero2 = 2 cards; opp_weights = dict or array over opponent 2-card holdings (None = uniform); runouts sampled or enumerated. `canon3(cards3) -> int` (0..1754). |
| `discard.py` | W3 | `choose_discard(hole3, flop, opp_model, dead, budget_ms, rng) -> int`; `opp_discard_policy(triple3, flop) -> int` (uses only the opponent's own cards + public info); `posterior_after_discard(d_v, flop, prior, beta) -> weights over ≤ 990 pairs` (03/D3). |
| `preflop.py` | W4 | `strength(hole3) -> float` (table lookup, equity vs random); `decide(req, hand_state, opp) -> dict`. Data: `bot/data/preflop.json` (generated by `scripts/offline/build_preflop_table.py`). |
| `betting.py` | W5 | `decide(req, hand_state, opp, clock, rng) -> dict` for the flop (3 hole cards, before the discard) and turn/river (2 cards). |
| `opponent.py` | W6 | `class OppModel`: `observe_action(...)`, `observe_showdown(...)`, `stat(name) -> float`, `archetype_weights() -> dict`, `range_weights(street, history) -> weights`. A neutral default implementation must exist from day 1 (W1 stub). |
| `params.py` | all | Tunables only, one section per workstream (`# --- W5 ---`). No logic. |

Rules:
- **Pure functions where possible**, so they can be tested without the engine.
- Every function that can take time gets a `budget_ms` or `clock`, and stops on time.
- No module except `bot.py` writes to stdout. Debug logging goes through a `log()` helper to stderr, off by default.
